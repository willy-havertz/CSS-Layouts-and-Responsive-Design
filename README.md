# 🌐 Responsive Webpage Project

This project demonstrates a fully responsive webpage using **modern CSS techniques** including **Flexbox**, **CSS Grid**, and **Media Queries**. It adapts to various screen sizes (mobile, tablet, desktop) and includes a mobile-friendly toggle navigation menu built with HTML and CSS only.

## 🚀 Features

- 📱 Fully responsive layout
- 🔲 CSS Grid for structured content sections
- 📦 Flexbox for navigation layout
- 📋 Media queries for mobile and tablet views

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)


## 🧪 How to Use

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Resize the window or use DevTools to test responsiveness.
